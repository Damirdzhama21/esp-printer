# Принтер без компьютера за 6 000 ₸

### Обычный USB-принтер печатает из Telegram-бота через плату ESP32-S3

Раньше у принтера в конторе стоял ноутбук, и нужен он был только для печати из бота. Теперь вместо ноутбука там плата размером со спичечный коробок. Документ отправляют с телефона, через 20 секунд лист уже в лотке.

В этом комплекте всё, чтобы собрать такое себе: готовая прошивка, её исходники, сервер и пошаговая инструкция.

---

## Как это устроено

```
Телефон: PDF в Telegram-бота (или ваш код шлёт PDF на сервер)
   ↓
Сервер: очередь, PDF → растр в формате принтера (ghostscript)
   ↓  интернет
Плата ESP32-S3 у принтера: раз в 4 секунды «есть что печатать?»
   ↓  USB-кабель
Принтер печатает → плата сообщает серверу «готово»
```

**Плата ничего не понимает в документах.** Всю тяжёлую работу делает сервер: превращает PDF в картинку, которую принтер понимает без драйвера. Плата просто переносит готовые байты из интернета в USB. Драйвер не нужен нигде, компьютер у принтера тоже.

**Плата сама ходит на сервер,** а не сервер на неё. Белый IP, проброс портов и настройка роутера не нужны: работает в любой сети с Wi-Fi и интернетом.

## Что понадобится

| Что | Примерно | Комментарий |
|---|---|---|
| Плата **ESP32-S3** с двумя разъёмами USB-C (проверено на YD-ESP32-S3 N16R8) | 4–5 тыс. ₸ | Нужна именно **S3**: у неё есть USB Host. Обычная ESP32, C3, C6 не подойдут |
| Кабель USB-C ↔ USB-B (квадратный, принтерный) | 1 тыс. ₸ | Или переходник на ваш кабель |
| Блок питания от телефона, 5 В 1 А и больше | есть у всех | |
| Кабель USB-C **с данными** | есть у всех | Только для прошивки. Зарядный «только питание» не подойдёт |
| Сервер с публичным адресом | от 2 тыс. ₸/мес | Любой VPS. Лучше с доменом и HTTPS |
| Паяльник | | Одна капля припоя |

**Принтер:** проверено на HP LaserJet M28a. Должен подойти почти любой USB-принтер, который умеет печать без драйвера: в характеристиках есть «AirPrint», «Mopria», «IPP Everywhere» или «driverless». Таких сейчас большинство. Старые принтеры только с «GDI»-драйвером не подойдут.

## Шаг 1. Сервер

Сервер держит очередь и готовит растр. Нужен Docker.

```
cd server
cp .env.example .env
openssl rand -hex 24      # это будет PRINTER_TOKEN
openssl rand -hex 24      # это будет ADMIN_TOKEN
nano .env                 # вписать оба токена
docker compose up -d --build
docker compose logs -f    # должно быть «сервер печати на порту 8080»
```

Без Docker: поставьте Node.js 18+ и ghostscript (`apt install ghostscript`), затем `PRINTER_TOKEN=... ADMIN_TOKEN=... node server.mjs`.

**HTTPS.** Плата умеет и `http://`, и `https://`. Через интернет лучше HTTPS: токен идёт в заголовке. Проще всего поставить перед сервером Caddy или Traefik с Let's Encrypt. Сертификаты Let's Encrypt плата понимает из коробки.

### Печать из Telegram

1. В @BotFather создайте бота, токен впишите в `TG_BOT_TOKEN`.
2. Перезапустите сервер, напишите боту что угодно. Он ответит: «Нет доступа. Ваш id: 123456».
3. Впишите этот id в `TG_ALLOWED_IDS` (несколько через запятую), перезапустите.
4. Теперь любой PDF, отправленный боту, уходит на печать. Бот сообщит «в очереди» и «напечатано».

### Печать из своего кода

```
curl -X POST --data-binary @document.pdf \
     -H "x-admin-token: ВАШ_ADMIN_TOKEN" -H "x-name: Накладная 15" \
     https://ваш-сервер/api/print
```

Так печатают из любого бота или CRM: заказ на кухню, накладная, чек. Сервер принимает PDF, остальное сделает сам.

## Шаг 2. Подготовить плату

У платы два разъёма USB-C:

- **COM**: питание и прошивка;
- **USB**: сюда подключается принтер.

На обратной стороне есть площадка-перемычка **USB-OTG**. Её **нужно запаять** каплей припоя. Без этого на разъём USB не идёт 5 вольт, и принтер плату не увидит. Это единственная пайка во всём проекте.

Перемычку **IN-OUT** не трогайте. Перемычка **RGB**, если есть, должна быть запаяна, иначе не будет гореть цветной огонёк (печать при этом работает).

## Шаг 3. Прошить

Плату подключаем кабелем к разъёму **COM**.

**Windows, macOS, Linux, без установки чего-либо:** откройте в Chrome или Edge сайт espressif.github.io/esptool-js, нажмите Connect, выберите порт платы, адрес `0x0`, файл `esp-printer-full.bin`, Program.

**Linux / macOS скриптом:**

```
cd dist
./flash.sh
```

Скрипт сам поставит esptool и найдёт порт.

**Если прошивка не начинается:** зажмите **BOOT**, нажмите и отпустите **RST**, отпустите BOOT и попробуйте ещё раз.

**Linux, «нет доступа к порту»:** `sudo usermod -aG dialout $USER`, выйдите из системы и зайдите снова.

После прошивки нажмите **RST**.

## Шаг 4. Подключить у принтера

- **COM** → в зарядку от телефона.
- **USB** → кабелем в принтер.
- Принтер включён.

## Шаг 5. Настроить с телефона

1. Огонёк мигает синим: плата ждёт настройки и подняла свою Wi-Fi сеть.
2. Подключитесь к сети **ESP-Printer**, пароль **printer2026**.
3. Страница настройки откроется сама. Если нет, откройте `http://192.168.4.1`.
4. Выберите свою сеть Wi-Fi, введите её пароль.
5. **Токен принтера:** ваш `PRINTER_TOKEN` из `.env`.
6. **Адрес сервера:** например `https://print.example.com` (без слэша в конце, путь `/api/...` плата добавит сама).
7. «Сохранить и перезагрузить». Через полминуты огонёк зелёный. Готово.

Проверка: отправьте PDF боту или через curl. В логах сервера будет «отдал плате задание», потом «напечатано».

**Сменить сеть или сервер:** при включённой плате держите **BOOT** 5 секунд, огонёк замигает часто, настройки сотрутся. Не держите BOOT в момент включения питания: так плата уходит в режим прошивки (просто нажмите RST).

### Что значит огонёк

| Цвет | Что значит |
|---|---|
| жёлтый | запускается (пара секунд) |
| жёлтый мигает | принтер только что подключился, ждём, пока проснётся |
| синий мигает | нет Wi-Fi, открыта сеть ESP-Printer для настройки |
| зелёный | всё хорошо, ждёт задания |
| белый | печатает |
| красный горит | не видит принтер: кабель в разъёме USB, включён ли принтер, запаяна ли перемычка USB-OTG |
| красный мигает | ошибка: неверный токен, нет интернета, сервер не отвечает или принтер не принял данные |

### Страница платы

В той же сети откройте `http://<адрес платы>/` (адрес видно в списке устройств роутера, имя `esp-printer`). Там состояние, принтер, тонер, последняя ошибка, а по ссылке «журнал» подробный лог.

## Обновление прошивки

Чтобы не вводить заново Wi-Fi и токен, шейте **только приложение** с адреса `0x10000`:

```
esptool.py --chip esp32s3 write_flash 0x10000 esp-printer-update.bin
```

Полный образ с `0x0` стирает все настройки.

## Как плата говорит с сервером

Если хотите встроить печать в свой сервер, а не брать готовый, нужны три адреса. Плата шлёт токен в заголовке `x-pechat-token` и своё состояние в `X-Plata` (прошивка, принтер, тонер, ошибки).

| Запрос | Ответ |
|---|---|
| `GET /api/pechat/esp/vzyat` | `204`, если заданий нет. `200`: тело = PWG raster, заголовки `X-Zadanie-Id` и `Content-Length` обязательны. `403`: неверный токен |
| `POST /api/pechat/esp/gotovo` тело `{"id":5,"ok":true}` или `{"id":5,"ok":false,"oshibka":"…"}` | `200`. `404`, если задание уже не ваше (плата перестанет повторять отчёт) |
| `GET /api/pechat/esp/pulse` | `200`. Плата шлёт раз в минуту, когда принтер не подключён |

PDF в формат принтера:

```
gs -q -dBATCH -dNOPAUSE -dSAFER -sDEVICE=pwgraster -r600 \
   -dcupsColorSpace=18 -dcupsBitsPerColor=8 \
   -sPAPERSIZE=a4 -dFIXEDMEDIA -dPDFFitPage \
   -sOutputFile=out.pwg in.pdf
```

600 dpi, оттенки серого, около 470 КБ на страницу. `-dPDFFitPage` растягивает маленький бланк (например A5) на лист, иначе он печатается в углу.

Важно: пока плата не прислала отчёт, задание не отдавайте второй раз. Если отчёта нет 10 минут, верните задание в очередь. Так сделано в `server.mjs`.

## Грабли, на которые я наступил

Это самое ценное, на каждую ушло по полдня. Все обходы уже в прошивке, но если будете её править, не убирайте их.

**1. Документы подряд склеивались в один.** Если слать принтеру голый поток, у него нет «конца задания»: принтер ждёт паузу. Три документа подряд выходили одним листом, а сервер считал, что напечатаны все три. Решение: каждое задание отправлять отдельным IPP Print-Job (IPP-over-USB).

**2. «Напечатано» врало.** Принтер отвечает «принял» и «свободен», а лист ещё не вышел, и потом вылезают дубли. Решение: брать номер задания из ответа принтера и спрашивать статус именно этого задания, пока не скажет «завершено». Не напечаталось за 3 минуты: отменить задание на принтере, чтобы оно не вылезло потом повтором.

**3. Принтер HP шлёт пакеты больше, чем сам заявил** (512 байт вместо 64). ESP32-S3 видит это как ошибку и получает ноль байт. Обход: перед подключением поправить размер пакета в описании устройства и включить `CONFIG_USB_HOST_HW_BUFFER_BIAS_IN=y`.

**4. IPP у HP живёт на альтернативных настройках интерфейса** (alt 1). Нужно явно отправить SET_INTERFACE, библиотека ESP-IDF этого сама не делает.

**5. Принтер после переподключения тупит.** Если сразу слать задание, он принимает его медленно и зависает. Решение: после подключения ждать минимум 20 секунд и пока принтер сам не скажет «готов».

**6. Иногда HP вешает IPP целиком.** Тогда плата сама переходит на старый простой канал печати (с паузой между заданиями) и возвращается на IPP, когда принтер ожил.

**7. Плата висит без присмотра.** Сторожевой таймер перезагружает её, если что-то зависло, а задание не теряется: ждёт на сервере.

**8. Длинное описание у МФУ.** У принтеров со сканером описание USB-устройства больше, чем ESP-IDF принимает по умолчанию. Нужно `CONFIG_USB_HOST_CONTROL_TRANSFER_MAX_SIZE=2048`.

## Если не работает

| Что видно | Что делать |
|---|---|
| Красный горит | Проверьте перемычку USB-OTG, кабель в разъёме **USB** (не COM), включён ли принтер |
| Красный мигает, на странице «403» | Токен на плате не совпадает с `PRINTER_TOKEN` |
| Красный мигает, «сервер недоступен» | Адрес сервера, открыт ли порт, нет ли опечатки в https |
| Синий мигает после настройки | Неверный пароль Wi-Fi или сеть 5 ГГц: плата умеет только 2,4 ГГц |
| Задание «напечатано», а листа нет | Посмотрите журнал платы. Если принтер не поддерживает IPP-over-USB, он не подойдёт |
| Лист печатается мелко в углу | Проверьте `-dPDFFitPage` и `PAPER` |
| На странице «перезапустите принтер» | Выключите принтер кнопкой, включите, нажмите RST на плате |

## Собрать прошивку из исходников

Нужен ESP-IDF 5.3. Проще через Docker:

```
cd firmware
docker run --rm -v "$PWD":/project -w /project espressif/idf:release-v5.3 \
  sh -c 'idf.py set-target esp32s3 && idf.py build'
```

Имя сети и пароль настройки, адрес сервера по умолчанию лежат в `firmware/main/obshchee.h`. Если ставите платы клиентам, поменяйте пароль `AP_PAROL` на свой.
